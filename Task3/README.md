# Task 3: Context-Anchored Answering (RAG Basics)

## Overview

This project demonstrates the basics of **Retrieval-Augmented Generation (RAG)** using Python and the Gemini API.

The system answers questions using only the information provided in a reference document.

## Reference Content

The reference content can be based on any relevant document or topic.  
**Sony Group Corporation (Japan)** is used as an example in this project.

## Key Concepts

- Retrieval-Augmented Generation (RAG)
- Context-Anchored Answering
- Grounded Responses
- Information Not Found

## Technologies

- Python
- Gemini API
- Google GenAI SDK
- python-dotenv

## Testing

- Information available → Correct answer with supporting sentence.
- Information unavailable → `Information Not Found`.
